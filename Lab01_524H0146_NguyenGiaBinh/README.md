# Lab 01 · Nguyễn Gia Bình · 524H0146

Windows, Visual Studio 2022, .NET Framework 4.8 Developer Pack.



Chạy từ thư mục chứa solution sau khi giải nén ZIP source. Các lệnh chạy hai server cần hai terminal.

dotnet run --project Desktop/Desktop.csproj

Để lấy 10 ảnh giao diện từ Windows, mở terminal ở thư mục solution rồi chạy: dotnet run --project Desktop/Desktop.csproj -- --capture . Giữ form hiển thị, không che cửa sổ; ảnh được lưu vào Evidence/.
