# Lab 04 · Nguyễn Gia Bình · 524H0146

Windows, Visual Studio 2022, .NET Framework 4.8 Developer Pack.

Kết nối (localdb)\MSSQLLocalDB trong SSMS. Chạy School.sql một lần trên instance có quyền tạo database. 

Chạy từ thư mục chứa solution sau khi giải nén ZIP source. Các lệnh chạy hai server cần hai terminal.

powershell -ExecutionPolicy RemoteSigned -File .\Prepare.ps1
Sau đó mở Site bằng Visual Studio > Open > Web Site; đặt Default.aspx làm Start Page, chạy IIS Express.
