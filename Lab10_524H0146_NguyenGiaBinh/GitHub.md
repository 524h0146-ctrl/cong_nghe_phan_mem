Tạo remote trên GitHub bằng tài khoản của bạn. Giải nén ZIP mã nguồn; mở thư mục có solution trong terminal, tạo .gitignore của Visual Studio. Sau đó:
git init -b main
git add .
git commit -m "Add lab solution and report assets"
git remote add origin <URL-repo-cua-ban>
git push -u origin main
Sau khi xác nhận, lưu URL thật và chụp trang commit vào báo cáo.
